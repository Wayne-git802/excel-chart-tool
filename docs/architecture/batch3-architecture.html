🔍 Batch 3 — InsightEngine 架构设计

主动数据探索 · 多维检测器 · 洞察排序 · 自动推送 → 图表

核心流程

  • ① Trigger → InsightEngine.run(df, context)
  • ② InsightIntake: 列类型推断 + 基数分析
  • ③ 5 个检测器并行 (asyncio.gather)
  • ④ InsightRanker: 加权评分 → Top-3
  • ⑤ InsightPusher: SSE push → ChatPanel 渲染
  • ⑥ 用户点击 [生成图表] → ChartBuilder

评分公式

  • score = 0.35 × effect_size_norm
  • + 0.25 × surprise (与基线偏离度)
  • + 0.25 × actionable (能否生成图表)
  • + 0.15 × confidence (p-value / 样本量)
  • 去重: 同列+同类型取最高分
  • 阈值: score ≥ 0.3 才推送
