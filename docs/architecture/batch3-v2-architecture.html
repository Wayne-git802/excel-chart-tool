🔍 Batch 3 v2 — InsightEngine 修正架构

新增: DeduplicationLayer · SignificanceGate · UserModeGate · Insight→Story Bridge

🔵 新增: DeduplicationLayer

  • ① Rule Merge: 同列 + 同方向趋势 → 取最强检测器
  • ② Semantic Cluster: title 文本相似 > 0.8 → 合并
  • ③ 合并时保留 score 最高的那个
  • ④ 合并后预计 15-30 条 → 5-15 条
  • ⑤ 不做 embedding (太重)，用规则 + 关键词

⚠️ 新增: SignificanceGate

  • surprise 权重从 0.25 降到 0.15
  • surprise 必须过两道关卡:
  • ① n_samples ≥ 30 (小样本不配叫 insight)
  • ② p < 0.05 或 FDR 校正后
  • 未通过的 → surprise=0，不丢弃但降权
  • effect_size 权重从 0.35 升到 0.40

🚦 新增: UserModeGate

  • explore: 全量分析 + 主动推送 (默认)
  • analyze: 全量分析但只存 AnalysisGraph
  • visualize: 跳过 InsightEngine 直接画图
  • 前端顶部 3 个 tab 切换模式
  • ChatPanel 首条消息可切换模式

🌉 Insight → Story Bridge

  • 每个 Insight 生成一条 Hypothesis
  • Hypothesis → StoryNode (挂载到 AnalysisGraph)
  • StoryNode 携带 chart_spec_hint
  • ChatPanel 侧边栏展示 StoryTimeline
  • 用户可展开/折叠/回溯任意分支
  • 为 Batch 4 StoryBuilder 铺路

修订后评分公式

  • effect_size × 0.40 (原 0.35 ↑)
  • surprise × 0.15 (原 0.25 ↓，必须过 gate)
  • actionable × 0.30 (原 0.25 ↑)
  • confidence × 0.15 (不变)
  • 去重后 Top-3 → 推送 (explore 模式)
  • 阈值: score ≥ 0.3
